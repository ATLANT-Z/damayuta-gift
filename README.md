# damayuta-gift

Онлайн-версия подарочного сертификата Damayuta, оформленная как музейная экспозиция: надпись сверху, карточка в парящей золотой рамке, табличка-подпись снизу, фон — сумеречное небо с созвездиями (сгенерирован в Higgsfield). Серебро переливается жемчужным отливом от наклона (мышь, палец или гироскоп), за курсором рождаются маленькие созвездия. Карточка перелистывается как страница книги в обе стороны: свайпом или нажатием на правую или левую половину.

Сайт: https://atlant-z.github.io/damayuta-gift/

## Персональная ссылка

Ссылку проще всего собрать в конструкторе: https://atlant-z.github.io/damayuta-gift/link/ — три поля и кнопка «Скопіювати».

Имена в ссылке пишутся обратимой латиницей (`translit.js`), чтобы ссылка открывалась везде: Telegram Desktop не открывал ссылки с кириллицей.

```
https://atlant-z.github.io/damayuta-gift/?dlya=Olena&vid=Andrij&id=0042
```

- `dlya`: кому (имя появится и на стартовом экране)
- `vid`: от кого
- `id`: номер сертификата

Как читать латиницу: обычная буква — одна латинская (Олена → Olena), особая — буква с меткой `x` (ж zx, ч cx, ш sx, щ wx, ю ux, я ax, є ex, ї ix, ґ gx, ы yx, ё ox, э qx), ь → w, ъ → q, пробел → `_`, апостроф → `~`.

Старый формат `?to=Олена&from=Андрій` тоже работает; конструктор использует его для имён, которые латиницей не записать (например, John).

Без параметров поля остаются пустыми, как на печатном макете.

## Файлы

- `index.html`: вся страница, без зависимостей кроме Google Fonts
- `front.webp`, `back.webp`: стороны карточки (из TIFF A5 300 dpi, вылеты обрезаны)
- `og.jpg`: картинка для превью ссылки в мессенджерах
- `background.webp`: фон
- `link/index.html`: конструктор персональной ссылки
- `translit.js`: обратимая латиница для имён в ссылке
